# Screenshots

This directory contains screenshots of the Movie Database application showcasing its UI and features.

## Screenshots Included

1. **02-homepage-layout.png** - Homepage showing the main layout with navigation, Popular movies section, Kids section, Latest Trailers, Trending section, Join Us Today call-to-action, and footer
   
2. **03-homepage-movies-dropdown.png** - Navigation bar with Movies dropdown menu expanded showing options: Popular, Upcoming, Now Playing, and Top Rated

3. **04-movies-popular-page.png** - Popular Movies page with sorting options, filters, and "Where To Watch" functionality

4. **05-tv-shows-dropdown.png** - Navigation bar with TV Shows dropdown menu expanded showing options: Popular, Airing Today, On TV, and Top Rated

5. **06-tv-shows-popular-page.png** - Popular TV Shows page with similar layout to movies page including sort and filter options

6. **07-people-page.png** - Popular People page layout

## Notes

- Screenshots were taken in a development environment without live API access
- Images are placeholders showing the UI structure and layout
- The application requires API keys (TMDB API and Clarifai API) to display actual content
